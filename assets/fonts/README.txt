AnimeRenamer bundled UI fonts

Expected files:
- NotoSansCJKsc-Regular.otf
- NotoSansCJKsc-Bold.otf
- NotoSansMonoCJKsc-Regular.otf
- NotoSansMonoCJKsc-Bold.otf
- OFL.txt

Run tools\download_theme_fonts.ps1 to download the official Noto CJK font files.
The application registers these fonts privately for the current process on Windows; it does not install them system-wide.
